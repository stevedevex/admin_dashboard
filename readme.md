# tao sandbox — a learning project

A sample project for students and learners of REST and SOAP services. It builds a **mock admin
dashboard**: a backend that stands in for services an application depends on, and a frontend to
manage the mock data — using current, real-world tech rather than toy versions of it.

## What you will learn

**Backend — Java 25, Spring Boot 4**
REST and SOAP service mocking, contract-driven design (OpenAPI, WSDL), and modern Java on a
current Spring Boot release.

**Frontend — React 19, TypeScript, Vite**
A component-driven dashboard built with current React and a fast, modern build tool, talking to
the backend over a typed API layer.

**Full picture**
How a backend and frontend are structured to work together as one small, real application —
services, mock data, scenarios, and a UI to drive it all.
